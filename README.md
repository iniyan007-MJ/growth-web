# 🚀 Daily Growth App — v4 (Full Featured)

## Quick Start
1. Unzip → open `index.html` in browser
2. Register (enter gender) → Login → Done!

## ⚙️ Config (js/config.js)
All settings in one file:
```js
ai: {
  enabled: true,   // Set false to disable AI English feature
  apiKey: '...',
}
```

## 📁 Add Your Media Files
Put files here for 100+ reward:
- `assets/sounds/reward.mp3` → Song
- `assets/sounds/reward.mp4` → Video  
- `assets/images/reward.jpg` → Image

## 📊 Scoring
- Questions answered → up to 100pts total
- Extra tasks done → +5 bonus each (beyond 100)
- Reward button shows when score > 50

## 🏆 Reward Tiers
| Score | Reward |
|---|---|
| 50–70 | Strong motivational quote |
| 70–90 | Medium motivation |
| 90–100 | Quote + Chocolate animation 🍫 |
| 100+ | Quote + Song + Video + Image + Full celebration 🎊 |

## 🧠 AI Feature Off/On
In `js/config.js`: set `ai.enabled: false` to hide the AI English section completely.

## 👥 Friend Accountability  
Share your 8-char code → friend enters it → see each other's today score!

## 🌙 Dark Mode
Toggle button in topbar. Preference saved automatically.
